# SangamX Public Assets

Place any images, logos, or media assets in this `public` folder.

## How to replace the Hover Watermark Image:
1. Copy your desired image (e.g., photo, artwork, team image).
2. Rename it to `sangam.jpg` (or `sangam.png`).
3. Paste/overwrite it inside this `public/` directory (`c:\Users\HP\SangamX\public\sangam.jpg`).
4. The footer **SANGAMX** hover watermark text will automatically display your custom image on mouse hover!
